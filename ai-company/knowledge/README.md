# knowledge/

AIが判断に迷ったときに参照する資料置き場です。人間が書き足して育てます。

| ファイル | 内容 | 作成フェーズ |
|---|---|---|
| `my-voice.md` | 口調・文体のお手本（**あなたの文章に書き換えてください**） | フェーズ4 |
| `my-experience.md` | あなたの実体験・実績。AIはここにある数字だけを「実績」として使う | フェーズ4 |
| `themes.md` | 発信テーマ（AI副業の見極め、広告運用の小ネタ、AIツールの実務での使い方） | フェーズ4 |
| `compliance.md` | 規約・ステマ規制・AI生成表記のルール | フェーズ4 |
| `reports/` | 分析担当が書く週次レポート | フェーズ5 |

ここに書いた内容は「事実」として扱われます。不確かな数字は書かないでください。
