# note → X 変換

## System
X単体で価値のある投稿を書いてください。宣伝色を出さないでください。
7本は互いに書き出しと構成を変えてください（類似投稿の連投はXの自動化ルールで禁止されています）。
ハッシュタグは付けても1個までです。

## Input
- note タイトル: {{title}}
- Hook: {{hook}}
- 要点: {{key_points}}
- 結果（一次情報）: {{result}}
- URL: {{url}}
- 勝ちHook型: {{winning_hooks}}

## Task
次の7本を作ってください。
- 短文 ×3（140字以内。要点を1つずつ、それぞれ別の切り口で）
- ノウハウ ×2（箇条書き。手順型1本、失敗回避型1本）
- 長文 ×1（実験レポート。数字から書き始める）
- note誘導 ×1（無料部分で分かること、有料部分で手に入るものを書き、URLを付ける）

## Output (JSON)
[{"type": "short|knowhow|long|cta", "text": ""}]
